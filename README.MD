eCommerce Image Tool
-------------------

Author: Kristaps Lediņš aka [@krysits](https://segments.digital)

Technology used: PHP8

License: GPLv3

Description: Simple tool to resize and optimize images for eCommerce use.

Platforms supported: WooCommerce, Wolt.eu, Bolt.eu

Supports JPG, PNG, GIF, WEBP formats.

---

Usage:
1) copy your images to `input` folder
2) run `php ./jpg.php` command in terminal
   - for JPG images check `php ./h600.php` for 600px height lanscape images
   - for PNG images use `php ./png.php`
   - for GIF images use `php ./gif.php`
   - for WEBP images use `php ./webp.php`
   - for AVIF images use `php ./avif.php`
3) wait until script finishes
5) get your images in `square` or `landscape` folder
